# Preserved Rose 0.8 reference-v5 source

This directory preserves the exact previous source, renderer recipe, catalog, palette, body-reuse evidence, validation and review files used before the regional-spectrum update. The corresponding `static/art/*-v5.png` atlas bytes are retained unchanged.

The v6 body composition uses the per-frame `raw-body-checksums.json` here to pin all 1,152 inherited unquantized body/construct frames. Their actual original v4 source and renderer provenance remain in the inherited proof. The v6 palette is newly learned for regional practical lighting: current v6 body RGB may differ, while raw body renders, geometry, registration and exported alpha remain preserved. Use the current `docs/3D-SPRITE-PIPELINE.md` for the shipped recipe.
