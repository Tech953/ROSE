## Reproduce and use the repair

From the extracted `rose` directory:

```sh
python -m unittest discover -s tests -q
node tests/ui-smoke.cjs
```

The Node check runs a temporary real Python HTTP host and a modeled DOM. Native canvas adds asset decoding and image exports when available. Node is needed for this development check, not for playing.

Stop the old Rose host before launching the updated source. Its database remains in the existing Rose data directory. Keep a backup with the host stopped. Start with `Start-Windows.bat` on Windows or `python3 server.py` on Linux/macOS, then reconnect at the existing host address. If an automatic-update notice repeats after pause/resume, preserve the database and investigate the host's error before further playtesting.
